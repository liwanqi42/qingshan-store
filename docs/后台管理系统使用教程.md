# 青山商店管理后台使用教程

本教程面向店铺管理员和运营员工，按「登录 → 日常经营 → 商品维护 → 库存管理 → 员工权限」的顺序介绍青山商店管理后台的使用方法。

- 项目说明与部署方式见根目录 [README.md](../README.md)
- 管理端接口文档：开发环境启动后端后访问 `http://localhost:8080/doc.html`
- 默认地址：`http://localhost:8081`（本地开发）
- 默认管理员：`admin` / `123456`

> 首次登录后请立即修改默认密码。生产环境不要继续使用演示账号和默认密码。

## 1. 登录与界面

### 1.1 登录

1. 打开管理后台地址。
2. 输入用户名和密码，点击「登录」。
3. 登录成功后进入「工作台」。

登录规则：

| 项目 | 规则 |
| --- | --- |
| 用户名 | 3–20 位字母、数字或下划线 |
| 密码 | 6–20 位 |
| 记住账号 | 只记住用户名，不保存密码 |
| 登录失败锁定 | 同一账号连续失败 5 次，或同一 IP 连续失败 20 次，锁定 15 分钟（默认配置） |
| 登录失效 | Token 过期或后端密钥变更后，接口返回 401，自动跳回登录页并提示重新登录 |

登录页会把当前访问地址带到 `redirect` 参数中，重新登录后会尽量回到原页面。

### 1.2 界面布局

```text
┌─────────────────────────────────────────────────────────────┐
│  Logo        ☰ 面包屑                         用户名 ▾      │
├──────────────┬──────────────────────────────────────────────┤
│              │  已打开页面标签：工作台 × | 订单管理 × | ...   │
│   侧边栏      ├──────────────────────────────────────────────┤
│   功能菜单    │                                              │
│              │              当前页面内容                     │
│              │                                              │
│  更多管理     │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- **左上角 ☰**：展开 / 收起侧边栏。
- **面包屑**：显示当前页面层级，可点击返回上级。
- **标签页**：记录已打开页面。
  - 点击标签切换页面；
  - 点击 `×` 关闭标签；
  - 鼠标中键也可关闭标签；
  - 右侧下拉菜单支持「刷新当前」「关闭其他」「关闭全部」；
  - 「工作台」是固定标签，不能关闭。
- **右上角用户名**：下拉菜单包含「修改密码」「退出登录」。
- **更多管理**：侧边栏底部入口，收纳权限管理、菜单管理、字典管理、店铺管理等低频功能。

### 1.3 修改密码与退出

1. 点击右上角用户名 →「修改密码」。
2. 输入原密码、新密码、确认新密码。
3. 新密码长度 6–20 位，且不能与原密码相同。
4. 保存成功后会被强制退出，需要重新登录。

退出登录会断开 WebSocket，并清理本地登录态和已打开标签。

### 1.4 权限与可见范围

系统内置两个角色：

| 角色编码 | 角色名称 | 默认菜单 |
| --- | --- | --- |
| `admin` | 超级管理员 | 全部菜单 |
| `employee` | 普通员工 | 工作台、员工管理 |

- 菜单是否显示由后端返回的 `menuPaths` 决定，按路由名称匹配。
- 角色和菜单权限修改后，员工需要**重新登录**才会生效。
- 普通员工默认只能查看员工列表和详情，不能新增、编辑、启停员工。
- 角色、员工写操作、库存单据审核等敏感操作由后端再次校验「当前登录人是否管理员」。
- 「菜单管理」的显示/排序/图标配置保存在当前浏览器 `localStorage`，不会影响其他电脑或员工。
- 「字典管理」同样保存在当前浏览器，属于本地配置。

## 2. 工作台

工作台用于查看今日经营概览，登录后默认进入。

### 2.1 今日经营指标

| 指标 | 统计口径 |
| --- | --- |
| 今日营业额 | 今日「已完成」订单的实付金额合计 |
| 有效订单 | 今日「已完成」订单数量 |
| 订单完成率 | 有效订单数 / 今日订单总数 |
| 平均客单价 | 今日营业额 / 有效订单数 |
| 新增用户 | 今日新增用户数量 |

### 2.2 订单总览

展示今日各状态订单数量：

- 待付款
- 待接单
- 待发货
- 配送中
- 已完成
- 已取消
- 全部订单

> 工作台的订单总览只统计**今天**的订单，不是全部历史订单。

### 2.3 商品 / 套餐总览

展示当前已上架、已下架的商品和套餐数量。

### 2.4 刷新

- 页面每 60 秒自动刷新一次（仅当浏览器标签处于可见状态）。
- 也可以点击右上角「刷新数据」手动刷新。

## 3. 数据统计

「数据统计」用于查看指定日期范围内的经营趋势，仅管理员默认可见。

### 3.1 日期筛选

- 默认展示最近 7 天（含今天）。
- 修改日期范围后点击「查询」。
- 「重置」恢复默认最近 7 天。
- 日期范围包含开始日期和结束日期。

### 3.2 图表说明

| 图表 | 内容 |
| --- | --- |
| 营业额统计 | 每日营业额折线图 |
| 用户统计 | 每日用户总量、新增用户折线图 |
| 订单统计 | 每日订单数柱状图 + 有效订单数折线图 |
| 销量 Top10 | 指定日期范围内销量最高的 10 个商品名称与销量 |

订单统计上方显示：

- 订单总数
- 有效订单数
- 订单完成率

> 有效订单和营业额只统计「已完成」状态的订单。

### 3.3 导出报表

点击「导出报表」，下载 Excel 运营数据报表。

- 报表内容为**截至昨天的近 30 天**经营数据。
- 包含概览数据和每日明细。
- 导出与页面当前选择的日期范围无关。

## 4. 订单管理

订单管理是日常使用最频繁的页面。

### 4.1 查询订单

支持以下筛选条件：

| 条件 | 说明 |
| --- | --- |
| 关键词 | 订单号或商品名称 |
| 手机号 | 收货人手机号 |
| 状态 | 待付款 / 待接单 / 待发货 / 配送中 / 已完成 / 已取消 / 退款 |
| 下单时间 | 开始日期至结束日期 |

- 点击「查询」应用条件。
- 点击「重置」清空条件。
- 顶部三个统计卡片可点击，快速筛选「待接单」「待发货」「配送中」；再次点击取消筛选。

### 4.2 查看订单详情

点击任意订单的「详情」，右侧抽屉展示：

- 订单号、订单状态、下单时间、支付方式、实收金额
- 收货人、手机号、收货地址、订单备注
- 快递公司、物流单号
- 取消原因 / 拒单原因
- 售后状态、售后类型、售后原因、退款金额、申请时间、完成时间
- 拒绝原因、退货物流、退货时间
- 订单商品明细（图片、商品、规格、数量、金额）

### 4.3 订单状态

| 状态值 | 管理端显示 | 说明 |
| --- | --- | --- |
| `1` | 待付款 | 用户已下单但未支付，15 分钟后自动取消并回滚库存 |
| `2` | 待接单 | 用户已支付，等待商家接单或拒单 |
| `3` | 待发货 | 商家已接单，等待派送 |
| `4` | 配送中 | 已派送 / 发货，等待完成 |
| `5` | 已完成 | 订单结束 |
| `6` | 已取消 | 超时、用户取消或商家拒单 |
| `7` | 退款 | 售后退款完成 |

> 管理端的「待发货」对应数据库状态 `3`；数据库状态 `2` 在管理端显示为「待接单」。

### 4.4 订单操作

不同状态下可执行的操作：

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| 待接单（`2`） | 接单 | 状态变为待发货（`3`） |
| 待接单（`2`） | 拒单 | 填写拒单原因；状态变为已取消；已支付订单自动退款，回滚库存并扣减销量 |
| 待发货（`3`） | 派送 | 状态变为配送中（`4`），记录发货时间 |
| 配送中（`4`） | 完成 | 状态变为已完成（`5`），记录完成时间 |
| 待付款 / 待接单 / 待发货（`1/2/3`） | 取消订单 | 填写取消原因；状态变为已取消；已支付订单自动退款，回滚库存并扣减销量 |

> 存在售后记录（申请中 / 待退货 / 待收货 / 售后完成）的订单，接单、拒单、派送、完成、取消等按钮会隐藏，需先处理售后。

操作提示：

- 「接单」「派送」「完成」会弹出确认框。
- 「拒单」「取消订单」必须填写原因，内容不能为空。
- 拒单和取消属于不可逆操作，请确认退款和库存影响后再执行。

### 4.5 售后处理

订单列表的「售后」列展示售后状态：

| 状态值 | 管理端显示 | 可执行操作 |
| --- | --- | --- |
| `1` | 售后申请中 | 同意售后 / 拒绝售后 |
| `2` | 待买家退货 | 等待买家填写退货物流 |
| `3` | 买家已退货待商家收货 | 确认收货 |
| `4` | 售后完成 | 无 |
| `5` | 售后被拒绝 | 无（订单可继续履约） |
| `6` | 售后关闭 | 无 |

#### 同意售后

点击「同意售后」，填写售后处理备注后确认。系统根据售后类型和订单发货状态处理：

| 售后类型 | 订单是否已发货 | 处理结果 |
| --- | --- | --- |
| 仅退款 / 退货退款 | 未发货（待接单 / 待发货） | 立即退款，回滚库存，扣减销量 |
| 仅退款 / 退货退款 | 已发货（配送中 / 已完成） | 进入「待买家退货」，等买家填写退货物流 |
| 换货 / 补寄 | 任意 | 只完成售后，不发起退款，订单保持已支付 |

#### 拒绝售后

点击「拒绝售后」，必须填写拒绝原因。

- 售后状态变为「售后被拒绝」。
- 订单状态不变，可继续接单、派送、完成。
- 拒绝原因会在小程序售后详情中展示。

#### 确认收货并退款

当售后状态为「买家已退货待商家收货」时，点击「确认收货」：

1. 确认已收到买家退回的商品。
2. 确认后系统立即退款给买家。
3. 回滚库存并扣减销量。

> 请务必在真实收到退货后再点击「确认收货」，该操作会立即退款。

### 4.6 订单管理注意事项

- 支付成功的新订单会通过 WebSocket 推送「来单提醒」。
- 用户点击「催发货」会推送「催发货提醒」。
- 订单超时取消由后端定时任务每分钟扫描一次，默认 15 分钟。
- 管理端取消 / 拒单会触发退款时，退款失败则操作不会完成，订单保持原状态。
- 售后处理中不要重复点击，系统有并发保护和状态校验。

## 5. 库存管理（入库 / 出库 / 台账）

库存管理包含三个页面：

- **入库管理**：创建入库单，审核后增加库存。
- **出库管理**：创建出库单，审核后扣减库存。
- **库存台账**：查看手工出入库审核产生的库存流水。

> 库存台账只记录手工入库 / 出库，不记录销售下单、退款、商品编辑直接改库存。

### 5.1 新建入库单 / 出库单

1. 进入「入库管理」或「出库管理」。
2. 点击「新建入库单」或「新建出库单」。
3. 在顶部快速录入框输入**商品编号**或**SKU 编号**，设置数量后按回车或点击「添加」。

快速录入规则：

- 输入 SKU 编号（如 `1001-1`）会直接定位到对应 SKU。
- 输入商品编号（如 `1001`）：
  - 商品只有一个规格：直接加入；
  - 商品有多个规格：弹出规格选择框，选择本次出入库的 SKU；
  - 商品没有规格：按商品汇总库存处理。
- 重复扫描 / 输入同一商品和 SKU，会自动累加数量，不会新增重复行。
- 已禁用的 SKU 不能添加。
- 商品已有 SKU 时，必须选择具体 SKU，不能按商品汇总出入库。
- 单据最多 200 行明细，单行数量范围 `1–999999`。
- 备注最多 200 个字符。

4. 核对明细、数量、备注后点击「保存待审核」。
5. 新单据状态为「待审核」，不会立即改变库存。

### 5.2 查询单据

支持按以下条件筛选：

- 单据编号
- 商品编号或 SKU 编号
- 状态：待审核 / 已审核
- 创建日期范围

列表展示：单据编号、商品种数、总数量、状态、制单人、创建时间、审核人、审核时间、备注。

### 5.3 编辑与删除

- 只有「待审核」单据可以编辑或删除。
- 「已审核」单据不可修改、不可删除。
- 编辑时不能修改单据类型（入库 / 出库），只能调整明细和备注。
- 删除待审核单据不会影响库存。

### 5.4 审核单据

1. 在「待审核」单据行点击「审核」。
2. 确认提示中的库存变化方向：
   - 入库：审核后**增加**库存；
   - 出库：审核后**扣减**库存。
3. 点击「确定审核」。

审核规则：

- **仅管理员可以审核**，普通员工看不到审核按钮，后端也会校验管理员身份。
- 审核后单据不可修改，库存立即变化。
- 审核时逐行处理，任意一行库存不足或商品 / SKU 已被删除，整张单据回滚，不会出现部分成功。
- 出库审核通过后，对应商品销量会累加。
- 审核前库存和审核后库存会记录在单据明细中。

### 5.5 查看、打印与导出

- **详情**：查看单据头信息、明细、审核前后库存和合计数量。
- **打印**：浏览器打开打印窗口；如被拦截，请允许本站弹出窗口。
- **导出 Excel**：按当前查询条件导出单据明细，包含类型、状态、商品、SKU、规格、数量、制单人、审核人、备注等。

### 5.6 库存台账

进入「库存台账」查看流水：

| 字段 | 说明 |
| --- | --- |
| 单据编号 | 入库 `RK...` / 出库 `CK...` |
| 类型 | 入库 / 出库 |
| 商品编号 / 商品名称 | 商品信息快照 |
| SKU 编号 / 规格 | SKU 信息快照 |
| 变动数量 | 入库显示 `+`，出库显示 `-` |
| 变动前 / 变动后 | 审核前后的库存 |
| 操作人 / 操作时间 | 审核人及审核时间 |

支持按类型、单据编号、商品编号 / SKU 编号、操作日期筛选，并导出 Excel。

### 5.7 库存操作建议

- **销售出库**由订单流程自动处理，不要为了销售订单手工建出库单，否则会重复扣减库存。
- **采购到货、盘点调整、样品领用**适合使用手工入库 / 出库。
- 商品编辑页也能直接修改 SKU 库存，但不会写台账；需要留痕时请使用出入库单。
- 发现库存不一致时，先查「库存台账」和订单扣减记录，再按盘点结果做入库或出库调整。
- 新建单据后应尽快审核；未审核单据不会占用或改变库存。

## 6. 分类、商品与套餐

### 6.1 分类管理

分类分为两种类型：

- **商品分类**（`type = 1`）：用于商品
- **套餐分类**（`type = 2`）：用于套餐

操作说明：

1. 支持按分类名称、分类类型查询。
2. 点击「新增分类」，填写名称、类型、排序。
3. 排序值越小越靠前。
4. 列表中的开关控制分类启用 / 禁用。
5. 分类名称不能重复。
6. 分类已被商品或套餐使用时不能删除，需要先迁移或删除关联数据。

> 商品编辑页只加载「商品分类」，套餐编辑页只加载「套餐分类」。

### 6.2 新增商品

进入「商品管理」→「新增商品」。

| 字段 | 说明 |
| --- | --- |
| 商品编号 | 必填且唯一，只能包含字母、数字、下划线、中划线，如 `1001`、`A-01` |
| 商品名称 | 必填且唯一 |
| 商品分类 | 必选商品分类 |
| 价格 | 必须大于 0，作为 SKU 默认价格 |
| 封面图片 | 必填，用于列表和详情首图 |
| 商品轮播图 | 最多 6 张 |
| 详情长图 | 最多 20 张 |
| 描述 | 选填 |
| 状态 | 上架 / 下架，新商品默认下架 |

图片通过后端上传到阿里云 OSS，单文件最大 5MB。

### 6.3 商品规格与 SKU

商品支持多规格组合，例如「颜色 + 尺码」。

操作方式：

1. 在「商品规格」区域点击「添加规格」。
2. 一行填写一个规格名，如「颜色」。
3. 在该行输入规格值，按回车或输入逗号后继续添加，如「黑色」「灰色」「白色」。
4. 同一规格的多个值必须放在同一行，不要拆成多行。
5. 系统会自动组合生成 SKU，并显示「当前将生成 N 个 SKU 组合」。
6. 在「SKU 列表」中为每个组合设置价格、库存和可选图片。

规则：

- SKU 编号自动生成，格式为 `商品编号-序号`，如 `1001-1`、`1001-2`。
- 修改商品编号后，SKU 编号会按新编号重新生成。
- 至少保留一个 SKU。
- 每个 SKU 价格必须大于 0，库存不能为负数。
- 无规格商品会保留一个默认 SKU。
- 修改商品价格时，价格为空 / 为 0 / 等于原商品价格的 SKU 会跟随更新；已单独定价的 SKU 不受影响。
- 删除规格值会同步删除包含该值的 SKU；新增规格值会自动补充缺失的组合。
- 商品列表和库存单中的库存是 SKU 库存合计，由后端维护。

### 6.4 编辑、上下架与删除

- 点击「编辑」修改商品信息、图片、规格和 SKU 价格库存。
- 列表开关直接控制上架 / 下架，用户端只展示上架商品。
- 删除限制：
  - 上架商品不能删除，需先下架；
  - 被套餐引用的商品不能删除；
  - 支持勾选多行批量删除。
- 删除商品会同时删除其规格、SKU 和图片记录。

### 6.5 套餐管理

套餐用于把多个商品组合销售。

新增套餐：

| 字段 | 说明 |
| --- | --- |
| 套餐名称 | 必填 |
| 套餐分类 | 必选套餐分类 |
| 套餐价格 | 必须大于 0；页面会显示套餐内商品总价作为参考 |
| 套餐图片 | 选填 |
| 描述 | 选填 |
| 状态 | 上架 / 下架，新套餐默认下架 |
| 套餐商品 | 添加商品并设置份数，份数范围 1–99 |

规则：

- 套餐内商品可重复调整份数，不能重复添加同一商品。
- 上架套餐前，套餐内所有商品必须处于上架状态，否则上架失败。
- 只有下架套餐可以删除。
- 套餐价格由商家自行设置，不强制等于商品总价。

## 7. 员工管理

「员工管理」用于维护后台登录账号。

### 7.1 查看员工

- 支持按员工姓名查询。
- 列表展示姓名、用户名、手机号、角色、性别、状态、创建时间。
- 点击「详情」查看员工完整信息（身份证号已脱敏）。

### 7.2 新增员工

仅管理员可操作。点击「新增员工」，填写：

| 字段 | 说明 |
| --- | --- |
| 用户名 | 3–20 位字母、数字或下划线，登录使用 |
| 姓名 | 2–20 个字符 |
| 手机号 | 11 位手机号 |
| 角色 | 选择一个已启用角色 |
| 性别 | 男 / 女 |
| 身份证号 | 需符合格式校验 |

说明：

- 新增员工初始密码统一为 `123456`，员工首次登录后应自行修改。
- 新员工默认启用。
- 角色被禁用时不能分配给员工。

### 7.3 编辑员工

仅管理员可操作。

- 可修改用户名、姓名、手机号、角色、性别、身份证号。
- 用户名仍然需要保持唯一，修改后员工下次登录需使用新用户名。
- 身份证号在列表中脱敏展示；编辑时保留脱敏值表示不修改原身份证号。
- 内置 `admin` 账号不允许修改角色，避免管理员自锁。

### 7.4 启用 / 禁用

仅管理员可操作。

- 开关关闭后，该员工无法登录后台。
- 已登录的 Token 在有效期内仍可能继续使用，敏感操作会重新校验角色；建议员工离职时同时修改密码或轮换密钥。

### 7.5 普通员工的权限

普通员工默认只能：

- 查看工作台
- 查看员工列表和员工详情

不能新增、编辑、启停员工，也不能访问订单、商品、库存、统计等菜单（除非角色被分配了对应菜单）。

## 8. 权限管理（角色与菜单）

「权限管理」用于维护角色及其可访问菜单，仅管理员可写操作。

### 8.1 角色列表

展示角色名称、角色编码、菜单数量、状态和操作按钮。

系统内置角色：

| 编码 | 名称 | 说明 |
| --- | --- | --- |
| `admin` | 超级管理员 | 拥有全部菜单和全部操作权限，不能删除、不能禁用 |
| `employee` | 普通员工 | 默认仅工作台和员工管理，可按需分配菜单 |

### 8.2 新增 / 编辑角色

- **角色名称**：必填。
- **角色编码**：以字母开头，只能包含字母、数字、下划线；创建后不可修改。
- **状态**：启用 / 禁用。
- 编码重复会提示错误。
- 角色被禁用后，绑定该角色的员工无法登录。

### 8.3 分配菜单权限

1. 点击角色行的「分配权限」。
2. 在菜单树中勾选允许访问的页面。
3. 点击「保存」。
4. 提示「员工下次登录后生效」。

注意事项：

- 菜单树按路由名称保存，例如 `DashboardView`、`OrderView`、`StockInView`。
- 工作台通常应保留；即使未勾选，前端路由守卫仍允许进入工作台，但侧边栏不会显示该菜单。
- 被分配菜单主要控制**菜单可见性和页面访问**；角色 / 员工写操作、库存审核等接口已额外校验管理员身份，但商品、订单等其他写接口仍主要依赖登录态和前端菜单控制，不能把菜单权限当成完整的后端鉴权。
- 修改权限后，已登录员工需要退出并重新登录。

### 8.4 删除与恢复默认

- 超级管理员角色不能删除。
- 已有员工绑定的角色不能删除，需要先把员工调整到其他角色。
- 「恢复默认」会把内置角色恢复为默认名称、启用状态和默认菜单：
  - 超级管理员：全部菜单
  - 普通员工：工作台、员工管理

## 9. 菜单管理

「菜单管理」用于调整当前浏览器中的菜单展示，不会写入后端。

### 9.1 可调整项

- 菜单名称
- 图标
- 排序（越小越靠前）
- 是否显示
- 是否移入「更多管理」

### 9.2 操作

1. 点击菜单行的「编辑」。
2. 修改名称、图标、排序、显示开关。
3. 开启「更多管理」后，该菜单从侧边栏移到左下角「更多管理」弹层。
4. 点击「保存」，当前浏览器立即生效。
5. 点击「恢复默认」可清除本地配置。

注意事项：

- 配置保存在当前浏览器 `localStorage`，不同电脑、不同浏览器互不同步。
- 菜单隐藏只影响显示，不改变角色权限；隐藏后的页面仍可通过直接访问 URL 打开（如果角色有权限）。
- 「更多管理」中的默认四项顺序固定：权限管理、字典管理、菜单管理、店铺管理；其他手动移入的菜单按排序追加。

## 10. 字典管理

「字典管理」用于维护界面展示用的枚举标签，例如员工性别。

### 10.1 字典结构

- **字典类型**：一组字典的编码和名称，如 `employee_sex`。
- **字典项**：类型下的具体选项，包含标签、值、标签样式和排序。

### 10.2 操作

1. 左侧选择字典类型。
2. 右侧查看、新增、编辑、删除字典项。
3. 新增字典类型：
   - 类型编码需以小写字母开头，只能包含小写字母、数字、下划线；
   - 类型编码创建后不可修改；
   - 类型不能重复。
4. 新增字典项：
   - 标签和值必填；
   - 同一类型下值不能重复；
   - 可选择标签样式（success / warning / danger / info 等）和排序。
5. 「恢复默认」清除当前浏览器的本地字典配置。

注意事项：

- 当前字典配置保存在当前浏览器 `localStorage`，不会同步到其他电脑。
- 系统内置字典更新后，页面会自动同步新增项；本地自定义项会保留。
- 后端字典接口尚未接入，后续可替换为持久化接口。

## 11. 店铺管理

「店铺管理」用于切换用户端首页展示的营业状态。

### 11.1 营业状态

| 状态 | 用户端表现 |
| --- | --- |
| 营业中 | 首页显示「营业中 / 正常接单」 |
| 打烊中 | 首页显示「已打烊 / 店铺休息中，暂不接单」 |

> 注意：当前版本后端下单接口**尚未强制校验**该状态。打烊主要用于向顾客展示营业信息，不能作为唯一的停单手段；需要真正停止接单时，还应下架商品或由运维侧限制下单接口。

### 11.2 切换状态

1. 进入「店铺管理」。
2. 点击「营业中」或「打烊中」卡片。
3. 在确认框中点击确定。

注意事项：

- 营业状态保存在 Redis，默认情况（Redis 无值）为**打烊中**。
- Redis 重启或清空后，状态可能回到打烊，需要重新设置。
- 切换后小程序首页下一次加载会读取最新状态。
- 打烊状态不改变已有订单，也不会自动取消订单。

## 12. 实时消息提醒

管理端登录后会自动建立 WebSocket 连接。

### 12.1 消息类型

| 类型 | 触发场景 | 标题 |
| --- | --- | --- |
| `1` | 用户支付成功产生新订单 | 来单提醒 |
| `2` | 管理端连接建立时存在待接单订单 | 待接单提醒 |
| `3` | 用户点击「催发货」 | 催发货提醒 |

### 12.2 表现形式

- 右下角弹出通知，持续 10 秒。
- 通知内容包含订单号或待接单数量。
- 点击右上角关闭可提前关闭。

### 12.3 连接机制

- 每 30 秒发送一次心跳。
- 断线后 5 秒自动重连。
- 退出登录时主动断开，不再重连。
- 消息不持久化，页面关闭期间的消息不会补发；重新登录建立连接时只补发「待接单」数量提醒。

### 12.4 收不到提醒时

- 确认浏览器页面处于打开状态。
- 确认后端和 WebSocket 代理正常。
- 检查 Nginx 是否转发 `/ws/` 并设置 `Upgrade` / `Connection` 头。
- 检查是否有多个后台标签页同时登录，消息会推送给所有在线会话。

## 13. 日常操作建议

### 13.1 开店前

1. 登录后台，确认右上角账号和角色正确。
2. 到「店铺管理」确认状态为「营业中」，保证小程序首页展示正常营业。
3. 到「商品管理」检查主推商品是否上架、价格和库存是否正确。
4. 到「库存管理」确认待审核单据已处理，避免库存未及时更新。

### 13.2 营业中

1. 关注「来单提醒」和订单管理顶部的「待接单」数量。
2. 及时接单或拒单；拒单必须填写原因。
3. 备货完成后点击「派送」，配送完成后点击「完成」。
4. 处理售后申请：
   - 未发货仅退款可直接同意；
   - 已发货退货退款需等待买家退货，收到货后再确认收货并退款；
   - 拒绝售后必须写清原因。
5. 采购到货使用「入库管理」，领用 / 报损使用「出库管理」，保存后及时审核。

### 13.3 闭店前

1. 检查是否有「待接单」「待发货」「配送中」订单未处理。
2. 检查售后申请是否已响应。
3. 在「库存台账」核对当日手工出入库流水。
4. 在「数据统计」查看当日营业额、订单完成率和销量 Top10。
5. 如不再接单，到「店铺管理」切换为「打烊中」；如需彻底停止下单，还要下架商品或联系运维限制下单接口。

### 13.4 账号与权限

- 管理员账号只用于管理，不要多人共用。
- 每个员工使用独立账号，按岗位分配角色。
- 员工离职及时禁用账号。
- 定期检查角色菜单权限，遵循最小权限原则。

## 14. 常见问题

### 14.1 登录提示账号锁定

同一账号连续失败 5 次或同一 IP 失败 20 次会锁定 15 分钟。请等待锁定时间结束，或由运维清理 Redis 中的限流数据。不要反复尝试。

### 14.2 登录后看不到某个菜单

- 当前账号的角色没有分配该菜单。
- 管理员到「权限管理 → 分配权限」勾选对应菜单。
- 员工退出并重新登录。
- 如果是「菜单管理」中被隐藏，可到「菜单管理」恢复默认。

### 14.3 订单没有「接单 / 派送 / 完成」按钮

- 按钮只在对应状态下出现：待接单可接单，待发货可派送，配送中可完成。
- 存在售后记录时，履约按钮会隐藏，需要先处理售后。
- 已完成、已取消、退款订单不能继续操作。

### 14.4 看不到「审核」按钮

- 只有管理员可以审核库存单据。
- 普通员工只能新建、查看、编辑、删除待审核单据，不能审核。
- 单据已审核时不再显示审核按钮。

### 14.5 编辑了商品库存，但库存台账没有记录

商品编辑页直接修改 SKU 库存不会写台账。需要留痕的库存变动请使用「入库管理 / 出库管理」并审核。

### 14.6 商品删除失败

- 商品处于上架状态：先下架再删除。
- 商品被套餐引用：先从套餐中移除该商品。
- 分类删除失败：分类下仍有商品或套餐。

### 14.7 套餐无法上架

套餐内至少有一个商品处于下架状态。请先上架所有包含商品，再上架套餐。

### 14.8 图片上传失败

- 检查后端 OSS 配置是否正确。
- 检查文件是否超过 5MB。
- 检查 Bucket 是否允许读取，AccessKey 是否有写入权限。
- 如果后端日志提示 OSS 异常，请联系运维检查网络和密钥。

### 14.9 打印窗口没有打开

浏览器拦截了弹出窗口。请允许本站弹出窗口后重新点击「打印」。

### 14.10 导出的 Excel 没有数据

- 单据导出要求当前查询条件下存在数据。
- 报表导出固定为截至昨天的近 30 天，与页面日期筛选无关。
- 库存台账只包含手工出入库审核流水，没有销售订单流水是正常的。

### 14.11 修改角色权限后没有立即生效

角色与菜单权限在员工下次登录时加载。请让员工退出后重新登录。

### 14.12 修改密码后仍能使用旧页面

修改密码成功后系统会清理登录态并跳转登录页。如仍有旧标签页，请关闭或刷新。
