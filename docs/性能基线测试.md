# 性能基线测试

> 目标：在 1 万订单量级确认商品列表、订单列表、报表导出没有明显退化，形成可重复的冒烟方法。
> 结果仅代表本地单机冒烟，不是生产压测。

---

## 1. 测试环境

| 项 | 值 |
| --- | --- |
| 操作系统 | Windows 11 Pro |
| JDK | Oracle JDK 23.0.2 |
| 应用 | 单实例，`qingshan-server-1.0-SNAPSHOT.jar`，端口 18082 |
| 数据库 | 本地 MySQL 9.6，独立库 `qingshan-perf` |
| 缓存 | 本地 Redis，与开发环境共用实例 |
| 数据量 | 10,000 订单 + 20,000 订单明细 + 25 商品（种子数据） |
| 订单时间 | 最近 30 天随机分布 |

> 测试库通过 `mysql/schema.sql`（数据库名替换为 `qingshan-perf`）+ `seed-base.sql` + `seed-demo.sql` 初始化，再执行 `scripts/perf-seed-orders.sql`。

---

## 2. 复现步骤

```bash
# 1. 创建独立测试库
DB_PASS='***'
sed 's/qingshan-store/qingshan-perf/g' mysql/schema.sql > /tmp/schema-perf.sql
sed 's/qingshan-store/qingshan-perf/g' mysql/seed-base.sql > /tmp/seed-base-perf.sql
sed 's/qingshan-store/qingshan-perf/g' mysql/seed-demo.sql > /tmp/seed-demo-perf.sql
mysql -u root -p"$DB_PASS" < /tmp/schema-perf.sql
mysql -u root -p"$DB_PASS" < /tmp/seed-base-perf.sql
mysql -u root -p"$DB_PASS" < /tmp/seed-demo-perf.sql
mysql -u root -p"$DB_PASS" qingshan-perf < scripts/perf-seed-orders.sql

# 2. 用测试库启动后端
java -jar apps/backend/qingshan-server/target/qingshan-server-1.0-SNAPSHOT.jar \
  --server.port=18082 --qingshan.snowflake.worker-id=6 \
  --qingshan.datasource.database=qingshan-perf

# 3. 冒烟
BASE_URL=http://127.0.0.1:18082 ROUNDS=20 ./scripts/perf-smoke.sh
```

## 3. 结果

| 接口 | 次数 | 平均 | 最小 | 最大 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `GET /user/product/page?page=1&pageSize=10` | 20 | **13 ms** | 8 ms | 25 ms | 首次请求后走 Redis 缓存 |
| `GET /admin/order/conditionSearch?page=1&pageSize=10` | 20 | **117 ms** | 69 ms | 387 ms | 含订单分页 + 每单明细查询 |
| `GET /admin/report/export` | 5 | **1.30 s** | 0.98 s | 2.46 s | 生成 xlsx，文件约 10.5 KB |

---

## 4. 结论与建议

1. 1 万订单量级下，三个目标接口均在可接受范围；订单列表是当前最需要关注的点（平均百毫秒级）。
2. 订单列表查询按 `order_time desc` 排序，当前表只有 `idx_user_status`、`idx_refund_status`。数据量继续增长（10 万+）前建议评估增加 `idx_order_time (order_time)`，并确认分页 `count` 的耗时。
3. 商品列表依赖 Redis 缓存，压测时应分别记录「缓存命中」和「缓存穿透」两种情况。
4. 本结果未覆盖并发；上线前建议在预发环境用 20–50 并发做一次只读压测，并观察 MySQL 连接池、Redis 命中率和 GC。
5. 报表导出为同步生成，订单量更大时容易超过网关超时，后续可改为异步任务 + 下载链接。
